# Дайджесты атласа

Тематические подборки для разных задач. В отличие от единственной категории, у приёма может быть любое количество дайджестов. Источник состава — свойство `digest` в карточках приёмов.


- [[atlas/! digests/todo|Управление задачами]] — `todo`
- [[atlas/! digests/teach|Преподавание]] — `teach`
- [[atlas/! digests/management|Управление проектами]] — `management`

Пример

```yaml
digest: [todo, management]
```

Без дайджеста]`.

Имена файлов и ID стабильны и записываются латиницей. Название хранится в `title`. Для нового дайджеста создайте карточку по образцу соседних и добавьте её ID в нужные приёмы. Состав в Obsidian обновляется через Bases.
