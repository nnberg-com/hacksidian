# Эксперименты с параметризованными приёмами

Поля находятся на карточках ниже. Корректные значения сохраняются в `recipe.css` приёма и сразу меняют пример. Для включённого приёма нажмите **Обновить уже существующий стиль**, чтобы перенести изменения в оформление. Выключение приёма сохраняет выбранные значения. «Сбросить» возвращает исходное значение одного параметра.

Приёмы помечены тегом #hacksidian_parameter_experiment.

| --- | --- |

| [[atlas/! hacks/note-dropcap/note-dropcap\|Буквица]] | Число с единицей em |
| [[atlas/! hacks/quote-corner-marks/quote-corner-marks\|Угловые кавычки]] | Короткий текст для двух знаков |
| [[atlas/! hacks/text-system-uswds/text-system-uswds\|USWDS]] | Межстрочный интервал текста |
| [[atlas/! hacks/image-e016/image-e016\|Мягкое скругление]] | Скругление относительно радиуса темы |
| [[atlas/! hacks/link-e014/link-e014\|Скруглённая плашка]] | Скругление и боковые поля плашки |
| [[atlas/! hacks/table-e015/table-e015\|Компактная плотность]] | Вертикальные и горизонтальные поля ячеек |
| [[atlas/! hacks/code-e011/code-e011\|Компактный листинг]] | Масштаб текста и межстрочного интервала |

| [[atlas/! hacks/heading-e019/heading-e019\|Черта на всю ширину]] | Толщина черты и отступ от заголовка H3 |

Не включайте все примеры одновременно: приёмы цитат могут переопределять друг друга; маркеры и плотность задач затрагивают общие списки. Текстовая система здесь пока одна; выбор между системами будет следующим экспериментом.
