# Текстовые системы

Значение поля `category`: `text-systems`. Десять согласованных композиций размеров, насыщенности и интервалов. Гарнитуры и базовый размер текста берутся из настроек пользователя.

Применяйте одну систему за раз, отключая предыдущую. Категория использует существующий текстовый сниппет: отдельный CSS-модуль не требуется.
