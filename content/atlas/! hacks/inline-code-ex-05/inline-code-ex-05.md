> Зачем
Для редакционного текста, где семантика code нужна, а моноширинность необязательна.

> Как работает
font-family:inherit сохраняет гарнитуру абзаца; отличие задают вес и подложка.

> Ограничения
Для посимвольного сравнения и выравнивания программного текста моноширинный шрифт удобнее.
