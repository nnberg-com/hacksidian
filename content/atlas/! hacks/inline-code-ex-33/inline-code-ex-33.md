```hacksidian-details
> Зачем
Чтобы длинный идентификатор не расширял колонку.

> Как работает
overflow-wrap:anywhere разрешает разрыв, если фрагмент иначе не помещается; дефис не добавляется. Padding расширяет подложку, но цвет фона и скругление приём не задаёт.
```
