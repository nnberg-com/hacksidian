```hacksidian-details
> Зачем
Полоса сверху для блока кода. Аналог приёма callout-technical-top.

> Как работает
Цвет верхней полосы выбирается из палитры. Толщина полосы и наличие остальных сторон рамки настраиваются.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
