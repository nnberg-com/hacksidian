```hacksidian-details
> Зачем
Сохранить читаемость при выделении текста.

> Как работает
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
::selection задаёт контрастные цвет и фон.

> Ограничения
Выделите несколько слов мышью: эффект виден только на выделенном тексте.
```
