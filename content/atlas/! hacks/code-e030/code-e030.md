```hacksidian-details
> Зачем
Видеть рекомендованную границу длины строки.

> Как работает
Номер колонки задаётся параметром; по умолчанию 72. Направляющая стоит после указанного числа моноширинных знаков.
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
Вертикальная направляющая отмеряется от начала code в единицах ch; фон движется с текстом.

> Ограничения
Прокрутите вправо до направляющей. ch основан на ширине нуля, а не на подсчёте Unicode-символов.
```
