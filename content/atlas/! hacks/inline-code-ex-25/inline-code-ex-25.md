```hacksidian-details
> Зачем
Для редакционного обозначения спорного фрагмента.

> Как работает
text-decoration-style:wavy; CSS не проверяет синтаксис и не определяет ошибку.

> Ограничения
Волна часто воспринимается как ошибка, поэтому назначать её всем code стоит только осознанно.
```
