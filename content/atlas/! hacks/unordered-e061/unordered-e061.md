```hacksidian-details
> Зачем
Сохраняет естественное направление списка на арабском языке.

> Как работает
direction: rtl задаётся в CSS для списка с арабским текстом; ручные атрибуты HTML не нужны.

> Ограничения
CSS задаёт направление отображения, но не язык содержимого. Настройка языка зависит от приложения.
```
