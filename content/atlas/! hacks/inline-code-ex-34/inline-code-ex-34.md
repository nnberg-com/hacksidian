> Зачем
Для крайне узких колонок, где приоритет — поместить всё.

> Как работает
word-break:break-all разрешает разрыв между буквами, даже когда целое слово можно было бы перенести.

> Ограничения
Менее удобно читать команды; обычно anywhere мягче.
