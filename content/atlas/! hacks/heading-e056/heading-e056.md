> Зачем
Позволяет открыть точный раздел и скопировать адрес из браузера.

> Как работает
Ссылка # написана обычным синтаксисом Markdown. CSS показывает её при наведении на h3 и при фокусе внутри.

> Ограничения
Требуется рендерер с автоматическими id заголовков. Адрес зависит от его правил; CSS сам id не создаёт.
