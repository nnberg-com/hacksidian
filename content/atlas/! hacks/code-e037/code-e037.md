> Зачем
Обозначить тип вставки без дополнительной строки в Markdown.

> Как работает
Поле «Надпись» задаёт текст шапки; допускается пустое значение.
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
Текст pre::before с собственной типографикой.

> Ограничения
Подпись одинакова у всех блоков, к которым применён CSS. Содержательный заголовок лучше хранить в Markdown.
