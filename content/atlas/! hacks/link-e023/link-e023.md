```hacksidian-details
> Зачем
Выделить ссылки волнистым подчёркиванием вместо обычной прямой линии.

> Как работает
`text-decoration-style: wavy` меняет форму подчёркивания ссылки на волну, а `text-decoration-thickness: 1.5px` задаёт толщину линии.

> Ограничения
Приём меняет уже включённое подчёркивание. Если текущая тема скрывает подчёркивания ссылок, сам по себе этот CSS их не включает.
```
