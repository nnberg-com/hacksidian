```hacksidian-details
> Зачем
Делает начала пунктов заметнее.

> Как работает
Параметры на карточке: размер и цвет маркера. Значения сохраняются в CSS приёма; для включённого оформления используется кнопка «Обновить уже существующий стиль».

font-size на ::marker увеличивает точку, не увеличивая буквы.

> Ограничения
Крупный нативный маркер может менять высоту первой строки. Для независимого размера используйте геометрический маркер из следующего раздела.
```
