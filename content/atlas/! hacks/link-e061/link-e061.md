```hacksidian-details
> Зачем
Обозначить формат по строке href. CSS не определяет MIME-тип; совпадение подстроки может быть ложным.

> Как работает
[href$=".pdf"] распознаёт суффикс, [href*=".pdf?"] — известную форму URL с query.
```
