```hacksidian-details
> Зачем
Когда моноширинный шрифт зрительно сидит выше соседнего текста.

> Как работает
position:relative и top сдвигают рисунок, сохраняя исходное место в строке.

> Ограничения
Это ручная поправка для конкретной пары шрифтов. Она не увеличивает межстрочное пространство.
```
