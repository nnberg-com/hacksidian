```hacksidian-details
> Зачем
Акцентировать строку учебного примера, задавая её номер рядом с кодом в Markdown.

> Как работает
Если обработчик плагина не запущен, пример показывает сообщение о необходимости его перезагрузить вместо молчаливого отсутствия выделения.
Поместите код в callout с заголовком > [!code-line|1,3-5,8]. После | перечислите номера строк и диапазоны через запятую. Нумерация начинается с 1; пустые строки тоже считаются. Например, 3 выделяет одну строку, 2-4 — диапазон, 1,3-5,8 — несколько участков. Цвет выделения выбирается из семантической палитры.

> Ограничения
Нужен включённый плагин Hacksidian с обработчиком диапазонов; один CSS произвольный список не разбирает. Работает в отрисованном callout и встроенном примере, включая обёртки .el-pre и отложенное появление кода. В примере подсвечены строки 1, 3–5 и 8. Переносы отключены, длинные строки прокручиваются. Неверная запись (0, 5-2, пустой элемент) отключает выделение; номера за пределами блока игнорируются. Код и текст при копировании не изменяются. Приём объединяет прежние code-e033 и code-e034.
```
