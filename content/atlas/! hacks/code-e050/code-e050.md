> Зачем
Сблизить два последовательных блока.

> Как работает
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
pre:has(+ pre) и pre + pre снимают зазор и задают разные поверхности.

> Ограничения
«Ввод/вывод» здесь выбран автором. CSS видит только соседние блоки; длинная цепочка потребует другой договорённости.
