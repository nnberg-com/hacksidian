> Зачем
Декоративный образ листа без внешнего изображения.

> Как работает
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
Кнопка копирования отодвинута на 30px от правого края; справа оставлено место под кнопку и уголок. Сам уголок не перехватывает клики.
Угол построен границами псевдоэлемента.

> Ограничения
Цвет внешней половины угла должен совпадать с окружающим фоном.
