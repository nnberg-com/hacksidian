```hacksidian-details
> Зачем
Помочь отличить блок, с которым сейчас работает читатель.

> Как работает
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
Цвет рамки выбирается из восьми семантических цветов палитры. При наведении или фокусе внутри блока появляется тень 0 .5em 1.2em #00000014 — как у callout-technical-shadow. Постоянные внешние поля оставляют место для размытия; размер рамки не меняется.

> Ограничения
Это дополнительный эффект для указателя. На сенсорном экране он не нужен для чтения.
```
