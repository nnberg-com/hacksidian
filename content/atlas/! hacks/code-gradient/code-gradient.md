```hacksidian-details
> Зачем
Растворяющаяся рамка для блока кода. Аналог приёма callout-technical-gradient.

> Как работает
Два слоя фона создают рамку, исчезающую к правому краю. Акцент выбирается из семантической палитры.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
