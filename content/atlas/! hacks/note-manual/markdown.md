# Сохранить полевые записи

## Порядок действий

1. Создать папку для прогулки.
2. Сохранить заметку и изображения рядом.
3. Проверить относительные ссылки.

## Структура папки

```
walk/
  notes.md
  assets/
    bay.svg
```

**Готово**, когда заметка открывается без сети.
