```hacksidian-details
> Зачем
Для дополнительного визуального отклика при чтении.

> Как работает
При наведении отдельно настраиваются фон и текст: свой цвет, цвета темы, семантические цвета, «Контраст» или «Как есть». По умолчанию фон — --text-highlight-bg, текст — как есть. Отступы, форма и размер не меняются. Контраст текста вычисляется к выбранному фону; если фон оставлен как есть — к --code-background.

> Ограничения
Наведите указатель на код. На сенсорном экране этот эффект не должен быть единственным способом получить информацию.
```
