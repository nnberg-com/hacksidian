> Зачем
Автоматически различать несколько листингов в пределах документа.

> Как работает
Поле «Подпись перед номером» заменяет слово «Пример». Его можно оставить пустым; номер продолжает отображаться.
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
CSS-счётчик сбрасывается на существующем родителе и увеличивается на pre.

> Ограничения
В CSS ниже .markdown означает существующего родителя текста. Нумеруются блоки, не строки.
