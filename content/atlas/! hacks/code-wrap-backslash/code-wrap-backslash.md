```hacksidian-details
> Зачем
Показать, что визуальная строка продолжает ту же исходную строку кода.

> Как работает
Каждая исходная строка сохраняется отдельно; её визуальные продолжения имеют отступ 2ch. Знак обратного слеша рисуется перед мягким переносом.
Длинные строки переносятся. Плагин измеряет расположение символов и рисует обратный слеш после последнего символа перед мягким переносом. При изменении ширины маркеры пересчитываются. Перед настоящим переводом строки маркер не ставится.

> Ограничения
Нужен включённый обновлённый Hacksidian. Обратный слеш — только визуальный знак: он не добавляется в исходник, выделяемый текст или результат копирования и не превращает строку в shell-команду с физическими переносами. Работает с отрисованным кодом, не с исходными строками CodeMirror. Для блоков длиннее 30 000 символов измерение отключено, чтобы не тормозить чтение. Рецепт меняет переносы и не предназначен для совмещения с приёмами горизонтальной прокрутки.
```
