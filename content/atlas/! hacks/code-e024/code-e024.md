```hacksidian-details
> Зачем
Подсказать, что за краем есть продолжение строки.

> Как работает
Цвета настраиваются парами полей: «источник» выбирает семантическую палитру, цвет темы или «свой цвет»; соседнее цветовое поле действует при выборе «свой цвет». Прозрачность декоративных слоёв сохраняется.
Перенос длинных строк отключён, чтобы появилась горизонтальная прокрутка. Четыре фона: два покрытия с attachment: local и две тени с attachment: scroll.

> Ограничения
В начале видна только правая тень; в середине — обе; в конце — только левая. Если строки помещаются целиком, теней нет. Прокрутите в обе стороны: тень исчезает у достигнутого края. Покрытия рассчитаны на однотонный фон.
```
