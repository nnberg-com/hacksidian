> Зачем
Помогает вести взгляд по многострочному техническому тексту.

> Как работает
repeating-linear-gradient повторяет фон с шагом, равным line-height; прокрутка сохраняет исходные строки.

> Ограничения
Полосы совпадают с визуальными строками при фиксированном интерлиньяже. Номера исходных строк без дополнительной разметки не создаются.
