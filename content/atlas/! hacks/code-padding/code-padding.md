```hacksidian-details
> Зачем
Разные поля по разным сторонам для блока кода. Аналог приёма callout-technical-padding.

> Как работает
Четыре независимых поля управляют внутренними отступами. Малое правое поле может оставить недостаточно места под штатную кнопку копирования.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
