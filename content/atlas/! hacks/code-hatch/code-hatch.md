```hacksidian-details
> Зачем
Штрихованный край для блока кода. Аналог приёма callout-technical-hatch.

> Как работает
Штриховка занимает только левый край. Ширина и семантический цвет настраиваются; внутреннее поле оставляет место для текста.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
