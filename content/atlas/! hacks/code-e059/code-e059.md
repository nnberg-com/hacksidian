```hacksidian-details
> Зачем
Сохранять название панели при чтении длинного вывода.

> Как работает
Внешние поля перенесены с pre на тело code. Шапка занимает всю ширину контейнера; текст шапки и кода имеют внутренние поля. Шапка остаётся на месте при вертикальной прокрутке.
Два простых списка: «Фон шапки» и «Линия под шапкой». В каждом восемь семантических цветов; отдельные HEX-поля и переключатели источника убраны.
Псевдоэлемент pre::before закрепляется у верхнего края прокручиваемого pre через position: sticky. Непрозрачный фон закрывает проходящий под ним текст.

> Ограничения
Прокрутите внутри блока: шапка остаётся наверху. Подпись статическая, не извлекает имя файла; для содержательного названия нужен текст Markdown.
```
