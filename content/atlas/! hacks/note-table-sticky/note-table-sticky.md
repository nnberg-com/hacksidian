```hacksidian-details
> Зачем
Длинный набор значений в компактной панели.

> Как работает
table получает display:block, ограничение высоты и overflow; th закрепляется sticky.

> Ограничения
Изменение display таблицы требует проверки доступности в целевом браузере; дополнительный wrapper в заметку не добавляется.
```
