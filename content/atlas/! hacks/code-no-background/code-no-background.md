```hacksidian-details
> Зачем
Прозрачный фон для блока кода. Аналог приёма callout-no-background.

> Как работает
Убирает заливку контейнера и вложенного code, оставляя видимым фон страницы.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
