```hacksidian-details
> Зачем
Для отделённого от букв контура, который не участвует в расчёте ширины.

> Как работает
outline и outline-offset рисуют внешнюю обводку.

> Ограничения
Обводка может подходить вплотную к соседним буквам: расстояние в потоке она не резервирует.
```
