```hacksidian-details
> Зачем
Независимо настроить цвета комментариев, переменных, строк, ключевых слов и других элементов кода.

> Как работает
Фон блока по умолчанию — «Как есть»: приём не переопределяет фон, заданный темой или другими приёмами. Можно выбрать свой цвет, один из восьми семантических цветов или «Контраст».
Для каждого из тринадцати цветов доступны источник (свой цвет, семантический или контрастный) и отдельное поле своего цвета. Они задают обычный текст, комментарии, ключевые слова, строки, числа и логические значения, функции и классы, операторы, свойства и параметры, переменные, пунктуацию, теги и константы, регулярные выражения. Приём использует переменные --code-* Obsidian; переменные кода получают отдельный цвет по классам синтаксического анализатора. Примеры JavaScript, Bash и HTML показывают разные виды токенов.

«Контраст» выбирает чёрный или белый через CSS contrast-color(): для текста и токенов относительно --code-background, для фона блока относительно --background-primary. На движках без contrast-color() используется приближённый выбор по светлоте OKLCH с порогом 0.65.

> Ограничения
Свои цвета не меняются при переключении палитры; семантические следуют её переменным --color-*. Начальные значения рассчитаны на светлый фон; для тёмного их нужно настроить. Укажите язык после открывающих трёх обратных кавычек. Анализатор определяет тип токена: например, обычные идентификаторы JavaScript могут остаться обычным текстом, а переменная Bash $HOME получает класс variable. Свойства и параметры используют общий нативный цвет. Приём меняет блоки кода в режиме чтения и токены блоков в редакторе; набор классов этих режимов может различаться. Другие приёмы, явно задающие цвета токенов, могут перекрыть настройку. Контраст текста рассчитывается по --code-background: если другой приём рисует иной фон напрямую через background или градиент, CSS не может автоматически прочитать его фактический цвет.
```
