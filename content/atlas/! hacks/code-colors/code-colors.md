```hacksidian-details
> Зачем
Независимо настроить цвета комментариев, переменных, строк, ключевых слов и других элементов кода.

> Как работает
Фон блока задаётся отдельным цветовым полем.
Тринадцать цветовых полей задают обычный текст, комментарии, ключевые слова, строки, числа и логические значения, функции и классы, операторы, свойства и параметры, переменные, пунктуацию, теги и константы, регулярные выражения. Приём использует переменные --code-* Obsidian; переменные кода получают отдельный цвет по классам синтаксического анализатора. Примеры JavaScript, Bash и HTML показывают разные виды токенов.

> Ограничения
Цвета заданы независимо от палитры и не меняются при её переключении. Начальные значения рассчитаны на светлый фон; для тёмного их нужно настроить. Укажите язык после открывающих трёх обратных кавычек. Анализатор определяет тип токена: например, обычные идентификаторы JavaScript могут остаться обычным текстом, а переменная Bash $HOME получает класс variable. Свойства и параметры используют общий нативный цвет. Приём меняет блоки кода в режиме чтения и токены блоков в редакторе; набор классов этих режимов может различаться. Другие приёмы, явно задающие цвета токенов, могут перекрыть настройку.
```
