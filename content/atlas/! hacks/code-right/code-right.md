```hacksidian-details
> Зачем
Боковая линия справа для блока кода. Аналог приёма callout-technical-right.

> Как работает
Настраиваются цвет из палитры, толщина, скругление линии и наличие фона. Линии принадлежат внешней панели, горизонтальная прокрутка — вложенному code.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
