```hacksidian-details
> Зачем
Для редкого выразительного токена; не для всей документации.

> Как работает
background-clip:text ограничивает градиент контурами букв. Прозрачный текст включается только внутри supports.

> Ограничения
Цветовой градиент не является синтаксической подсветкой.
```
