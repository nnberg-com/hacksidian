### Сохранить результат

Файл `field-notes.md` лежит рядом с изображениями. Открыть папку можно командой `cd notes`.

```sh
mkdir -p notes
cp field-notes.md notes/
ls notes
```

Команды создают папку notes, копируют заметку и показывают содержимое папки.
