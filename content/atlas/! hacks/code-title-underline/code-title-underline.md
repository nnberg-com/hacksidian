```hacksidian-details
> Зачем
Подчёркнутый заголовок для блока кода. Аналог приёма callout-technical-title-underline.

> Как работает
Напишите заголовок третьего уровня (###) непосредственно перед блоком кода. Цвет линии выбирается из палитры. Обрабатываются как соседние h3/pre, так и обёртки режима чтения Obsidian.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
