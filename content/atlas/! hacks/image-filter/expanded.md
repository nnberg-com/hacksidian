# Фильтр: все варианты

[[atlas/! hacks/image-filter/image-filter|Карточка приёма]]

Все примеры независимы. Просмотр не меняет выбранные параметры. «Выбрать этот вариант» сохраняет выбор; установленный стиль обновляется отдельно на карточке.

## Без фильтра

```hacksidian-expanded
{"--hacksidian-image-filter-choice": "none"}
```

## Чёрно-белый

```hacksidian-expanded
{"--hacksidian-image-filter-choice": "grayscale"}
```
