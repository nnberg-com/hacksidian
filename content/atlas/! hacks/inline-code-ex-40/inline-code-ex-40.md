```hacksidian-details
> Зачем
Чтобы увидеть предел вертикальных отступов у обычного inline.

> Как работает
Высокая подложка нарисована через ::before с отрицательным z-index. Изоляция текстового блока удерживает её позади текста внутри этого блока, не меняя межстрочный интервал.

> Ограничения
Подложка может заходить в межстрочное пространство, но не должна закрывать текст соседней строки. Приём использует ::before; другое оформление этого псевдоэлемента может конфликтовать с ним.
```
