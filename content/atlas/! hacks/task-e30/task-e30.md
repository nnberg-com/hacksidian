###### Один CSS для атласа и Obsidian

`recipe.css` — единственный источник приёма. Атлас подключает его в iframe без изменений. Кнопка «Применить hack» записывает тот же CSS в рабочий сниппет; повторное применение обновляет блок, Undo возвращает предыдущую версию.

Приём действует во всех заметках в режиме чтения, без дополнительных cssclasses. Выполненные пункты уходят вниз каждого списка задач, включая вложенные. Исходный Markdown и DOM-порядок не меняются. Обычные списки не затрагиваются.

```hacksidian-details
> Зачем
Держать открытые пункты наверху без редактирования исходника.

> Как работает
Flex-column и order меняют визуальное расположение.

> Ограничения
DOM и клавиатурный порядок остаются исходными. Это визуальная перестановка.
```
