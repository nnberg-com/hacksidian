```hacksidian-details
> Зачем
Видеть готовность списка ещё до чтения пунктов.

> Как работает
Проверяет список задач сразу после заголовка H2: если все флажки отмечены, показывает завершение, иначе — состояние «в работе». Учитывает обычную HTML-разметку и отдельные обёртки заголовка и списка в режиме чтения Obsidian. Без следующего списка задач подпись не добавляется.

Параметр «Подпись завершённого раздела» задаёт текст через CSS-переменную; по умолчанию — «готово». Можно ввести, например, «done» или оставить поле пустым. Разделитель и галочка сохраняются. Параметр «Подпись раздела в работе» задаёт текст незавершённого раздела; по умолчанию — «в работе». Оба поля независимы, допускают пустую строку и ограничены 40 символами. Для включённого оформления используйте кнопку «Обновить уже существующий стиль».

> Ограничения
Список (маркированный или нумерованный) должен непосредственно следовать за заголовком, без промежуточного абзаца. Вложенные задачи тоже учитываются. ID заголовка для этого приёма не нужен. Поддержка обычных строк заголовков в редакторе Live Preview не подтверждена: селекторы требуют отрисованный H2 и список, а не строки CodeMirror.
```
