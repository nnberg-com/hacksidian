```hacksidian-details
> Зачем
Будущая возможность для документов, владелец которых разрешает передачу размеров.

> Как работает
Внутри sizing.html добавлен meta name="responsive-embedded-sizing". Снаружи есть fallback и проверка синтаксической поддержки.

CSS заметки оформляет внешний элемент iframe; содержимое встроенного документа имеет собственные стили.

> Ограничения
Эксперимент. Не обещает CSS-автообновление высоты при динамических изменениях. Поддержку Obsidian нужно проверять отдельно.

CSS снаружи iframe не меняет фон, прокрутку и содержимое вложенной страницы. `height: auto` не подгоняет рамку под её содержимое; `object-fit` не кадрирует iframe как картинку. `frame-sizing` — экспериментальная возможность: распознавание свойства ещё не подтверждает поддержку протокола размеров.

Живой пример пока не готов: образец содержит iframe или интерактивный HTML, для которого ещё не реализован отдельный просмотрщик.
```
