```hacksidian-details
> Зачем
Точечный фон для блока кода. Аналог приёма callout-technical-dots.

> Как работает
Два поля регулируют шаг точек, отдельное поле включает рамку. Минимальный видимый шаг ограничен 2px.

> Ограничения
Приём оформляет отрисованные блоки в режиме чтения и встроенных примерах. Строки исходного кода в редакторе CodeMirror устроены иначе. Другие приёмы, меняющие те же свойства, могут перекрывать оформление.
```
