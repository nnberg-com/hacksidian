```hacksidian-details
> Зачем
Для сохранения пробелов с обычными возможностями переноса.

> Как работает
pre-wrap сохраняет последовательности; в отличие от break-spaces, концевые пробелы могут свисать.

> Ограничения
Нормализацию Markdown CSS не отменяет: исходные переводы строк CommonMark превращает в пробелы.
```
