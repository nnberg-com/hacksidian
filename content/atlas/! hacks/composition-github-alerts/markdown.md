# Подготовка нового выпуска

Пять типов показаны вместе для сравнения. В рабочей статье выбирайте только необходимые.

> [!NOTE] Архив выпусков
> Предыдущие версии остаются доступны в архиве выпусков.

> [!TIP]
> Сначала проверьте обновление на копии рабочего проекта — это ускорит повторную проверку.

> [!IMPORTANT]
> Перед обновлением сохраните конфигурацию: она понадобится при первом запуске новой версии.

> [!WARNING]
> Не закрывайте приложение, пока перенос данных не завершён.

> [!CAUTION]
> Удаление каталога резервных копий лишит вас возможности восстановить прежние данные.
