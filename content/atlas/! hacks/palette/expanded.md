# Палитра: варианты

[[atlas/! hacks/palette/palette|Карточка приёма]]

Все примеры независимы. Просмотр не меняет выбранные параметры. «Выбрать этот вариант» сохраняет выбор; установленный стиль обновляется отдельно на карточке.

## Flexoki — Light

Авторские Light/Dark; роли фона, текста и границ совпадают по смыслу. Акцент: cyan.

[Источник](https://stephango.com/flexoki)

```hacksidian-expanded
{"--hacksidian-palette-choice":"flexoki-1"}
```

## Solarized — Light

Авторская светлая палитра. Дополнительные состояния Obsidian получаются смешением; акцент выбран blue.

[Источник](https://ethanschoonover.com/solarized/)

```hacksidian-expanded
{"--hacksidian-palette-choice":"solarized-1"}
```

## Catppuccin — Latte

Светлый авторский вариант Latte. Акцент выбран mauve; роли перенесены из именованных токенов.

[Источник](https://github.com/catppuccin/catppuccin)

```hacksidian-expanded
{"--hacksidian-palette-choice":"catppuccin-1"}
```

## Gruvbox — Light medium

Авторские цвета; medium contrast. Pink повторяет purple: отдельного розового в исходной палитре нет.

[Источник](https://github.com/morhetz/gruvbox)

```hacksidian-expanded
{"--hacksidian-palette-choice":"gruvbox-1"}
```

## VS Code — Light Modern

Цвета интерфейса Microsoft с раскрытым include. Недостающие роли: terminal ANSI; orange назначен из цвета строк (наша адаптация).

[Источник](https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults/themes)

```hacksidian-expanded
{"--hacksidian-palette-choice":"vscode-1"}
```

## Material — Seed 6750A4 · Light

Наша фиксированная сборка: seed #6750A4, themeFromSourceColor. Восемь цветных ролей дополнены отдельными tonal palettes; не канонический набор Material.

[Источник](https://github.com/material-foundation/material-color-utilities)

```hacksidian-expanded
{"--hacksidian-palette-choice":"material-1"}
```

## Tailwind CSS — Slate + Indigo · Light

Наша сборка Slate + Indigo; роли и ступени выбраны нами. Точные OKLCH из установленного Tailwind, без загрузки Tailwind в пример.

[Источник](https://tailwindcss.com/docs/colors)

```hacksidian-expanded
{"--hacksidian-palette-choice":"tailwind-1"}
```

## Radix Colors — Slate + Iris · Light

Наша сборка Slate + Iris. Используются штатные ступени 1–12; дополнительные цвета — ступень 11 каждой шкалы.

[Источник](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale)

```hacksidian-expanded
{"--hacksidian-palette-choice":"radix-1"}
```

## IBM Carbon — WHITE

Готовые темы Carbon. Восемь цветных ролей взяты из IBM palette: ступень 60 для светлых вариантов; pink = magenta.

[Источник](https://carbondesignsystem.com/elements/themes/overview/)

```hacksidian-expanded
{"--hacksidian-palette-choice":"carbon-1"}
```

## IBM Carbon — G10

Готовые темы Carbon. Восемь цветных ролей взяты из IBM palette: ступень 60 для светлых вариантов; pink = magenta.

[Источник](https://carbondesignsystem.com/elements/themes/overview/)

```hacksidian-expanded
{"--hacksidian-palette-choice":"carbon-2"}
```

## Tinted / Base16 — Default Light

Представитель коллекции: Default от Chris Kempson. Pink повторяет base0E. Выбрана светлая схема Default, не весь каталог Tinted.

[Источник](https://github.com/tinted-theming/schemes)

```hacksidian-expanded
{"--hacksidian-palette-choice":"base16-1"}
```
