# Horizontal Blocks

[[atlas/! plugins/! plugins|Приёмы для плагинов]] · [[atlas/atlas|Атлас приёмов]]

[Horizontal Blocks](https://github.com/icodealchemy/horizontal-blocks) размещает Markdown в колонках с помощью блоков `horizontal` и `hblock`, разделённых строками `---`. Для живых примеров плагин должен быть установлен и включён.

Приёмы этого набора добавляются в сниппет `hacksidian-plugin-horizontal-blocks.css`.

```hacksidian-category
plugin-horizontal-blocks
```
