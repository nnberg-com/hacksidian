# Списки и задачи в длинной статье

Эта раскраска проверяет списки, нумерацию и задачи внутри связного текста: короткие, длинные, смешанные и вложенные варианты.

### Небольшое перечисление

Абзац вводит несколько равноправных признаков, которые удобнее увидеть отдельно:

- ширина строки;
- размер основного текста;
- расстояние между абзацами.

После списка статья продолжается и показывает обычный нижний интервал.

### Пункты разной длины

Короткий и длинный пункты должны начинаться на одной вертикали:

- короткое наблюдение;
- более длинное наблюдение, которое занимает несколько строк и позволяет проверить висячий отступ, межстрочное расстояние и положение следующего маркера;
- заключительный короткий пункт.

Следующий абзац помогает увидеть границу списка без дополнительного заголовка.

### Последовательность действий

Когда порядок важен, тот же материал превращается в нумерованную последовательность:

1. открыть раскраску в Reading view;
2. посмотреть на страницу целиком;
3. записать первую реакцию;
4. сравнить следующую версию с предыдущей.

Числа должны работать как единая колонка и не теснить текст.

### Задачи в процессе чтения

Список задач показывает сразу несколько состояний:

- [x] выбрать документ;
- [ ] проверить основной текст;
- [ ] посмотреть вторичные элементы;
- [-] отложить спорное решение;
- [?] вернуться к вопросу позже.

После списка важно сохранить различимость завершённых, открытых и нестандартных состояний без потери читаемости.

### Вложенная структура

Иногда один пункт раскрывается несколькими способами:

1. Сначала оценить основу.
   - размер текста;
   - длину строки;
   - общий ритм.
2. Затем проверить детали.
   - [x] ссылки;
   - [ ] таблицы;
   - [ ] диаграммы.
3. После этого вернуться к статье целиком.

Здесь одновременно видны разные маркеры, уровни отступа и вертикальные связи между строками.

### Задача с пояснением

- [ ] Проверить длинный пункт задачи, в котором объяснение занимает несколько строк и остаётся читаемым рядом с чекбоксом. Вторая строка должна начинаться по вертикали текста, а не под самим элементом управления.

Финальный абзац возвращает страницу к прозе. Списки должны ускорять просмотр материала, но не делать всю статью похожей на интерфейс менеджера задач.
