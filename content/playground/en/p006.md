# Tables in a long article

## This sample presents tables as part of an article's argument, from a small comparison to a dense structure with varied cell contents.

### A compact comparison

A paragraph frames a question that naturally leads to comparing three states.

| State | Impression | Action |
| --- | --- | --- |
| Cramped | Not enough space | Increase margins |
| Faint | Weak anchors | Check contrast |
| Noisy | Too many signals | Simplify accents |

The next paragraph concludes the idea and tests the spacing after the table.

### Column alignment

Numbers, names, and scores call for different alignment.

| Element | Role | Score |
| :--- | :---: | ---: |
| Body text | Foundation | 82 |
| Links | Navigation | 68 |
| Code | Technical layer | 74 |
| Callouts | Supplement | 61 |

The left column reads as a list, the centre forms an axis, and the right allows numbers to be compared.

### Formatting within cells

A table can contain ordinary Markdown elements.

| Feature | Example | Comment |
| --- | --- | --- |
| Emphasis | **important**, *gentle* | Styles within a line |
| Link | [[en/p000\|Start]] | Navigation accent |
| Code | `line-height` | Monospaced fragment |
| Highlighting | ==check this== | Local attention |
| Tag | #table | Metadata in context |

Ordinary text after the table lets you compare the same styles outside the grid.

### Long text within cells

| Observation | Possible cause |
| --- | --- |
| The line feels too long and the eye struggles to return to the start of the next line | The text column is too wide or line spacing is insufficient |
| Links constantly draw attention away from content and towards navigation | Excessive colour contrast or an overly heavy icon |
| Code looks like a separate application rather than part of the article | Inconsistent backgrounds, margins, or monospaced text size |

This table tests line wrapping, row height, and vertical alignment.

### A narrow table between long paragraphs

A longer paragraph precedes the final table. It keeps the compact structure from sticking to the text or creating an accidental pause that is too large for its content.

| Yes | No |
| :---: | :---: |
| Continue | Go back |

The final paragraph again fills the width of the text column. A good table reduces repetition while remaining part of the narrative, rather than a detached data grid without context.
