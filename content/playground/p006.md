# Таблицы в длинной статье

Эта раскраска показывает таблицы как часть аргумента статьи: от маленького сравнения до плотной структуры с разным содержимым ячеек.

### Компактное сравнение

Абзац формулирует вопрос, после которого естественно сравнить три состояния.

| Состояние | Впечатление | Действие |
| --- | --- | --- |
| Тесно | Мало воздуха | Увеличить поля |
| Бледно | Слабые опоры | Проверить контраст |
| Шумно | Много сигналов | Упростить акценты |

Следующий абзац завершает мысль и проверяет расстояние после таблицы.

### Выравнивание колонок

Числа, названия и оценки требуют разного способа выравнивания.

| Элемент | Роль | Оценка |
| :--- | :---: | ---: |
| Основной текст | Основа | 82 |
| Ссылки | Навигация | 68 |
| Код | Технический слой | 74 |
| Выноски | Дополнение | 61 |

Левая колонка читается как список, центральная образует ось, правая позволяет сравнивать числа.

### Форматирование внутри ячеек

Таблица может содержать элементы обычного Markdown.

| Возможность | Пример | Комментарий |
| --- | --- | --- |
| Выделение | **важно**, *мягко* | Начертания внутри строки |
| Ссылка | [[p001\|Начало]] | Навигационный акцент |
| Код | `line-height` | Моноширинный фрагмент |
| Подсветка | ==проверить== | Локальное внимание |
| Тег | #таблица | Метаданные в контексте |

Обычный текст после неё нужен для сравнения тех же начертаний вне сетки.

### Длинный текст в ячейках

| Наблюдение | Возможная причина |
| --- | --- |
| Строка кажется слишком длинной и взгляд с трудом возвращается к началу следующей строки | Большая ширина текстовой колонки или недостаточный интерлиньяж |
| Ссылки постоянно перетягивают внимание с содержания на навигацию | Слишком высокий цветовой контраст или тяжёлая иконка |
| Код выглядит отдельным приложением, а не частью статьи | Несогласованные фон, поля или размер моноширинного текста |

Эта таблица проверяет переносы строк, высоту рядов и вертикальное выравнивание.

### Узкая таблица между длинными абзацами

Перед последней таблицей идёт более длинный абзац. Он нужен, чтобы компактная структура не прилипала к тексту и не создавала случайную паузу, слишком большую для своего содержания.

| Да | Нет |
| :---: | :---: |
| Продолжить | Вернуться |

Финальный абзац снова занимает всю ширину текстовой колонки. Хорошая таблица сокращает повторения, но остаётся частью повествования, а не отдельной таблицей данных без контекста.
