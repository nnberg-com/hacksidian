# Общие CSS Variables внутри каждой категории

## Статус
Отложенное изменение, записано по поручению пользователя 2026-09-24. Требование зафиксировано; исследование, выбор архитектуры и реализация не начаты. Возвращаться к ним по отдельному поручению.

## Why
В категории callout проявилось различие между готовым оформлением и общими способами его подгонки: внутренние поля, интервал после заголовка, выравнивание и работа с иконкой. Сейчас сходные настройки могут быть самостоятельными приёмами, фиксированными декларациями или переменными конкретного рецепта. Например, недавно добавленные переменные интервала после заголовка имеют ID отдельного приёма в имени: это параметризация рецептов, но ещё не общий контракт категории.

Требование пользователя относится ко всем категориям, а не только к callout: все общие параметры должны всегда быть CSS Variables и универсально работать для всех готовых решений своей категории.

## What Changes
- Определить для каждой категории общий контракт параметров: семантика, CSS custom property, единицы, допустимые значения, область действия и правила значений по умолчанию.
- Каждый общий параметр представлен реальной CSS Variable и используется CSS всех готовых решений соответствующей категории. Одинаковые подписи полей у независимых переменных рецептов не заменяют общий контракт.
- Отличить общие параметры категории от параметров, специфичных для одного решения; проверить полноту на всём каталоге.
- Исследовать каскад, композицию приёмов, применение к установленному стилю, предпросмотр, сохранение значений и миграцию существующих параметров.
- Отдельно разобрать связь с «базовыми» и «уточняющими» решениями. Ни разделение интерфейса, ни режим «выбрать одно» пока не утверждены.

## Impact
Потенциально все категории атласа, recipe.css, метаданные параметров, редактор и чат параметров, компиляция, предпросмотр, обновление установленных стилей, генераторы и проверки. Точный объём определяется исследованием.

## Non-goals
- Реализация, массовая правка CSS или миграция пользовательских данных сейчас.
- Перестройка категорий, объединение карточек или введение взаимоисключения без отдельного решения.
- Одна глобальная переменная для всех категорий: универсальность требуется внутри категории; совпадение имён и значений между категориями пока не определено.
- Объявление каждого уникального свойства рецепта общим параметром.
- Изменение авторского vault, публикация, push или обновление удалённого индекса.
