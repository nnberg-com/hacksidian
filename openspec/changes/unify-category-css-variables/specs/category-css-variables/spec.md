## ADDED Requirements

### Requirement: Common parameters are CSS custom properties
Каждая категория SHALL представлять все свои общие параметры реальными CSS custom properties. Имя переменной и её семантика SHALL составлять общий контракт категории, а не отдельные независимые контракты каждого готового решения.

#### Scenario: Common setting is exposed
- **GIVEN** настройка признана общим параметром категории
- **WHEN** она предоставляется пользователю
- **THEN** значение представлено CSS custom property, которую использует CSS оформления
- **AND** подпись в UI или подстановка фиксированных деклараций не заменяют CSS Variable

### Requirement: Every ready-made solution supports the category contract
Все готовые решения категории SHALL использовать все общие параметры этой категории с согласованной семантикой. Наличие декларации без влияния на соответствующее оформление MUST NOT считаться поддержкой параметра.

#### Scenario: Change a common parameter in any solution
- **GIVEN** выбрано любое готовое решение категории и допустимое значение общего параметра
- **WHEN** это значение применяется к оформлению
- **THEN** соответствующее свойство меняется согласно контракту категории
- **AND** специфичные правила рецепта не делают общий параметр неработающим

#### Scenario: Add another ready-made solution
- **WHEN** в категорию добавляется готовое решение
- **THEN** проверка контракта выявляет отсутствующую или неработающую поддержку любого общего параметра
- **AND** решение с таким пробелом не считается полностью совместимым с контрактом категории

### Requirement: Coverage includes every category
Исследование и последующая проверка SHALL охватывать все категории каталога. Пилотная реализация только для callout MUST NOT считаться выполнением требования для всего каталога.

#### Scenario: Assess completion
- **WHEN** оценивается выполнение общего контракта
- **THEN** доступна матрица общих параметров и всех готовых решений для каждой категории
- **AND** неразрешённые конфликты и пробелы явно отмечены как незавершённая работа
