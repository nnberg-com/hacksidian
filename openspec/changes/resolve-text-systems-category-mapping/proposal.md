# Один приём с параметрами и expanded-страницей

## Статус
Решение пользователя от 2026-09-23 реализуется в рабочем дереве. Проверки и оставшиеся ограничения — в tasks.md. Изменение не архивировано и не опубликовано.

## Why
Отдельная категория text-systems и десять карточек обозначали варианты одного приёма. Палитры имели такую же проблему и специальный путь галереи. Это нарушало связь «категория — песочница — CSS» и мешало использовать общую параметризацию.

## What Changes
- Один text-system в категории text, десять значений параметра выбора. Каждый вариант явно описывает H1–H6: размер, интерлиньяж, насыщенность, стиль, отбивки, трекинг и регистр.
- Один palette в категории palette, один параметр выбора из 11 светлых вариантов. Индивидуальная семантическая палитра остаётся самостоятельным приёмом: она задаёт отдельные цвета, а не выбирает готовую палитру.
- Единая схема таблиц значений переменных внутри recipe.css; селекторы общие для всех вариантов. Подмена целых CSS-файлов не используется.
- Необязательная expanded.md в папке любого параметризованного приёма. Автор перечисляет все варианты или только рекомендованные сочетания; UI не строит декартово произведение автоматически.
- Ссылка с карточки; просмотр не меняет источник, явный выбор сохраняет параметры общим механизмом. Применение к установленному стилю остаётся отдельным действием.
- Страница text-systems перенесена в text-system/expanded.md. Категория text-systems удалена. Общий g-text и песочница text сохраняются, новый модуль не создаётся.
- Тёмные варианты, ветки и демонстрационные переключатели удаляются из текущего каталога; поддержка тёмного режима отложена в add-dark-appearance.

## Требования к источникам
Точные данные первоисточников проверяются заново. Если источник не описывает H1–H6 полностью, по прямому решению пользователя недостающие уровни дополняются на основе его данных и принципов с явной пометкой адаптации. Нельзя называть реконструкцию издательским стандартом. Гарнитуры и базовый размер текста остаются пользовательскими.

## Impact
Параметры, компиляция, общий предпросмотр, карточки, галереи, генераторы, каталог, документация и проверки. При явном включении нового приёма удаляются принадлежащие старым вариантам маркированные блоки того же модуля; ручной CSS сохраняется. Авторский vault не изменяется этой работой.

## Non-goals
Поддержка тёмного режима; публикация и push; обновление удалённого поискового индекса; изменение настроек или установка в авторский vault; автоматическое применение при просмотре expanded.
