# Параметры приёмов на CSS Variables

## Why
Карточки применяют фиксированный CSS; экспериментальные поля палитр управляют только демонстрацией. Пользователь должен настраивать конкретный приём прямо на карточке, сохраняя связь параметра с CSS Variable.

## What Changes
- Doxygen-комментарии описывают поля рядом с переменными в recipe.css.
- Значения сохраняются в этом же файле, сразу обновляют пример и отдельно переносятся в включённый стиль.
- Общий редактор используется во всех карточках.
- Первая экспериментальная подборка: четыре приёма и фильтрующий тег.

## Impact
CSS приёмов, карточки, сохранение в vault, путь обновления установленного блока, документация и тесты. Формат hack.json и приёмы без параметров сохраняются.

Выбор текстовой системы как параметр одного приёма остаётся следующим шагом: текущие реализации различаются не только значениями переменных. Палитры в этом наборе не мигрируются. Требование «одна категория — один CSS» здесь не решается.
