# Решение

Контракт и примеры: [docs/technique-parameters.md](../../../docs/technique-parameters.md).

Источник описания и текущего значения — recipe.css. Никакой дополнительной базы значений. Чистый parser/updater строится на PostCSS и заменяет точный участок исходника; UI и сохранение отделены от него. Vault.process предотвращает потерю конкурентных изменений; очередь сериализует ввод. Сравнение прежнего значения защищает от перезаписи той же переменной из другой карточки.

Предпросмотр использует существующее наблюдение за исходным CSS. Применение ждёт завершения записи. Обновление включённого приёма вызывает существующий addHack, заменяющий один маркированный блок; выключение сохраняет источник. Проверка значений включена в compileHack.

Ограничение: каталог обновлений пока не объединяет новые версии исходников с пользовательскими значениями. Экспериментальные CSS не перегенерируются. При расширении генераторов нужен отдельный явный контракт сохранения значений.
