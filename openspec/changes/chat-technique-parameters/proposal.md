# Изменение параметров приёма через чат

## Why
Параметры уже доступны в форме. Пользователь хочет описывать желаемые изменения словами: «сделай толще», «межстрочный интервал до максимума».

## What Changes
На собственной странице приёма чат получает актуальные аннотированные CSS Variables и возвращает значения полей. Сохраняет их тот же механизм, что обслуживает форму. Результат меняет источник и пример; при однозначной команде также включается приём или обновляется его установленный блок.

За пределами страницы приёма сохраняется поиск рекомендаций. Если запрос однозначно задаёт один приём и желаемые параметры, единственный поисковый ответ может одновременно рекомендовать и преднастроить его. Запрос поиска другого приёма на карточке также направляется в существующий каталог. Единственный найденный приём открывается в новой активной вкладке. При сомнении в команде применения стиль не меняется; несколько результатов остаются списком без изменений. При неясной настройке задаётся вопрос, при отсутствии параметра объясняется ограничение.

## Impact
Отдельная схема и prompt параметров, Responses-запрос без file_search, общая очередь записи CSS, защита от устаревшего контекста, история конкретных изменений и существующий журнал расходов. Произвольная генерация CSS не добавляется.
