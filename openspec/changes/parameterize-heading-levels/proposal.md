# Параметризовать уровень заголовка

## Why
Переносимое оформление заголовка не должно требовать отдельного приёма для каждого уровня Markdown.

## What Changes
- 103 приёма heading получают select H1–H6 с сохранением прежнего уровня по умолчанию.
- Общая компиляция меняет теги, обёртки .el-hN и ссылки на штатные переменные выбранного уровня.
- Пример на карточке меняет уровень только в копии Markdown для рендера.
- Собственные параметры приёмов сохраняются независимо.
- Исключены heading-e012, heading-e039, heading-e043: их смысл зависит от иерархии нескольких уровней.
- Четыре эффекта ссылок heading-e060/e061/e062/e064 ограничены ссылками выбранного заголовка.

## Impact
Компилятор, LiveExample, 103 рецепта и карточки, верификатор каталога, документация и тесты.

## Non-goals
Live Preview/Source mode, переработка иерархических приёмов, установка в авторский vault, визуальная приёмка всех эффектов.
