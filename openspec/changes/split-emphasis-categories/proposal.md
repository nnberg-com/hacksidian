# Отделить зачёркивание и сочетания выделений

## Why
Зачёркивание и составная Markdown-разметка имеют отдельный смысл и не должны смешиваться с одиночным emphasis.

## What Changes
- strikethrough («Зачёркивание»): emphasis-s28–s31, s37.
- emphasis-combinations («Сочетания выделений»): emphasis-s32–s35, включая тройное сочетание в s32 и зачёркивание с маркером в s35.
- В emphasis остаются 28 приёмов.
- У всех 37 приёмов убраны номера в видимых названиях; неясные названия уточнены короткими смысловыми словами.
- Технические ID сохранены ради ссылок и установленных CSS-блоков. Две новые категории имеют собственные модули, добавленные в конец manifest; предыдущие имена файлов не меняются.
- Ранее установленный приём переносится при явном обновлении через existing previousTargets; CSS оформления не изменяется.

## Impact
Карточки, навигация, CSS manifest, справка, проверки классификации и переноса установленного CSS.

## Non-goals
Переработка визуальных решений и составных приёмов; новая параметризация; переименование технических ID; установка в авторский vault.
