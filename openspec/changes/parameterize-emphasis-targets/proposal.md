# Выбор Markdown-цели оформления emphasis

## Why
Пользователь выбирает визуальное оформление независимо от Markdown-маркеров фрагмента. Привязка переносимых решений к одному тегу препятствует этому.

## What Changes
- Только emphasis-s04–s19 и emphasis-s21–s27 получают select «Применить к…»: bold, italic, highlight.
- Один набор правил компилируется для выбранного тега; компилятор общий для применения и предпросмотра.
- Каждый приём явно задаёт собственную типографику, фон и декоративные свойства для одинакового результата на разных целях.
- Значение по умолчанию сохраняет прежнюю цель, примеры показывают все три разметки.
- Выбор цели не мешает отдельным параметрам оформления.

## Impact
23 рецепта и карточки, общий компилятор параметризации, проверка каталога, unit- и браузерные проверки.

## Non-goals
Live Preview и Source mode; параметризация остальных приёмов; добавление собственных визуальных параметров; установка в авторский vault.

## Статус
Реализовано в рабочем дереве. Проверки описаны в tasks.md; установленный плагин не обновлялся.
