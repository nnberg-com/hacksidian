## Why

Пользователь может показать желаемое оформление на скриншоте, но не знать названия CSS-приёмов для его описания. Нужен поиск подходящих решений из существующего атласа по видимым признакам изображения.

Статус: отложенное требование по просьбе пользователя. Реализацию сейчас не начинать.

## What Changes

- Пользователь прикладывает выбранный скриншот и при желании поясняет, какой элемент оформления его интересует.
- Система выделяет видимые признаки, ищет соответствующие приёмы в атласе и объясняет, чем рекомендации похожи на пример.
- Ответ различает наблюдаемый внешний вид и неподтверждённые предположения о реализации; при неоднозначности уточняет задачу или сообщает об отсутствии подходящего приёма.
- Передача изображения начинается только по явной отправке пользователем. Данные об изображении учитываются в расходах запроса.

## Capabilities

### New Capabilities

- `screenshot-technique-search`: поиск существующих приёмов по скриншоту желаемого оформления.

### Modified Capabilities

Нет.

## Impact

Будущие изменения интерфейса вложений, построения запроса, поиска и проверки рекомендаций, учёта расходов, локализации и тестов. Требуется поддерживающая изображения модель; выбор и ограничения проверяются перед реализацией.

## Non-goals

- Не внедрять функцию сейчас.
- Не захватывать экран автоматически и не отправлять текущую страницу без действия пользователя.
- Не генерировать и не применять новый CSS автоматически.
- Не обещать точного воспроизведения картинки или восстановления её исходного CSS.
- Не создавать отдельный визуальный индекс всего атласа без обоснования необходимости.
