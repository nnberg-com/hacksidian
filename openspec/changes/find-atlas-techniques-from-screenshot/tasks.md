## 1. Подготовка после отдельного решения начать реализацию

- [ ] 1.1 Уточнить сценарии, форматы вложений и правила хранения изображений.
- [ ] 1.2 Проверить поддерживаемые API, модели и стоимость; выбрать и зафиксировать схему поиска.
- [ ] 1.3 Подготовить контрольные скриншоты: сходство, неоднозначность, отсутствие решения и нечитаемое изображение.

## 2. Реализация

- [ ] 2.1 Добавить выбор, просмотр и удаление вложения до явной отправки.
- [ ] 2.2 Реализовать анализ изображения и поиск с проверкой существования рекомендованных приёмов.
- [ ] 2.3 Добавить пояснения сходства, уточняющие вопросы и ответы об отсутствии решения на русском и английском.
- [ ] 2.4 Подключить журнал расходов и обработку ошибок без автоматического применения CSS.

## 3. Проверка

- [ ] 3.1 Проверить отсутствие отправки до подтверждённого действия и после удаления вложения.
- [ ] 3.2 Проверить выдуманные ID, неподтверждённые утверждения, ошибки API и учёт расходов.
- [ ] 3.3 Выполнить локальные проверки; живые платные проверки и визуальную оценку провести по отдельному поручению.
