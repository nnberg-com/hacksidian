## ADDED Requirements

### Requirement: User explicitly submits a visual reference
Система SHALL принимать выбранный пользователем скриншот и необязательное пояснение для поиска похожего оформления. Система MUST NOT отправлять изображение только из-за его выбора или автоматически захватывать экран.

#### Scenario: Submit reference
- **GIVEN** пользователь выбрал скриншот и указал «интересуют ссылки»
- **WHEN** он отправляет запрос
- **THEN** система анализирует оформление ссылок и ищет подходящие приёмы атласа

#### Scenario: Remove attachment before submission
- **WHEN** пользователь убирает вложение до отправки
- **THEN** изображение не отправляется в API

### Requirement: Recommendations are grounded in visible features and atlas entries
Система SHALL связывать рекомендации с видимыми признаками изображения и существующими записями активного каталога. Система MUST NOT выдавать предположение об исходном CSS, теме или плагине за установленный факт.

#### Scenario: Similar technique exists
- **WHEN** в каталоге найден приём с похожим видимым эффектом
- **THEN** ответ содержит ссылку на карточку и объясняет соответствие признакам изображения
- **AND** не обещает пиксельного совпадения или доказанной идентичности реализации

#### Scenario: No supported match
- **WHEN** в каталоге нет подтверждённого подходящего приёма
- **THEN** система сообщает об отсутствии решения, не выдумывая карточку

#### Scenario: Ambiguous image
- **WHEN** непонятно, какой из нескольких элементов изображения интересует пользователя
- **THEN** система задаёт уточняющий вопрос вместо уверенного произвольного выбора

### Requirement: Screenshot search preserves manual application and expense accounting
Система SHALL оставлять применение приёмов отдельным действием пользователя и учитывать фактическое потребление API в существующем журнале расходов. Неизвестный расход при ошибке MUST NOT подменяться нулём.

#### Scenario: Search completes or fails
- **WHEN** завершается попытка поиска по изображению
- **THEN** состояние попытки и доступные сведения о расходах сохраняются
- **AND** CSS и оформление vault не меняются автоматически
