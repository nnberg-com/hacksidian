# Образцовые сниппеты Hacksidian

Эти файлы входят в сборку плагина. При первой установке отсутствующие файлы копируются в `<vault>/<configDir>/snippets`, существующие остаются без изменений. Далее плагин редактирует только рабочие копии в vault. Не используйте эту папку как рабочий набор.

`hacksidian-manifest.json` сохраняет ID модулей для истории и Undo; числовые префиксы CSS задают порядок штатной загрузки Obsidian. `SOURCE-README.md` — историческое описание исходного набора, до добавления префикса `hacksidian-`.
