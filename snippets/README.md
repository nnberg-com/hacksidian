# Сниппеты Hacksidian: чистый лист

При первой установке плагин создаёт 22 пустых CSS-файла — по одному на группу. Они не содержат правил или значений переменных и не меняют оформление Obsidian, в том числе заметок с `cssclasses: callmered-coloring`.

Правила появляются после применения выбранных пользователем приёмов или ручного редактирования CSS. `hacksidian-manifest.json` задаёт структуру файлов; перечисленные в нём `nativeVariables` — справочные имена, а не значения настроек.

Первый запуск создаёт и включает только отсутствующие файлы. Существующие файлы и состояние их включения сохраняются. Обновление не сбрасывает пользовательское оформление; миграция старой структуры переносит её текущие значения.
