# Изменения CSS и учёт расходов

Обновлено 15 сентября 2026: ограничения на структуру CSS сняты. Модель возвращает в modules полный CSS только изменённых существующих сниппетов. Неупомянутые сниппеты программа сохраняет байт в байт; IDs, компоненты и порядок остаются прежними. За один запрос можно менять несколько сниппетов, добавлять и удалять селекторы и свойства, перестраивать правила и применять любые CSS-возможности. Состав файлов фиксирован. Из ограничений оформления сохранена проверка шрифтов по списку совместимых с выбранными языками.

Ранее внедрённый формат `moduleId/revision/edits`, разрешавший только изменение значений, больше не используется. Сохраняются проверка синтаксиса, защита от перезаписи параллельных изменений и Undo. Проверка сохранности структуры из исторического CSS-аудита не участвует в применении ответов модели.


Учёт хранится отдельно от разговора в apiAttempts внутри data.json. До вызова провайдера сохраняется попытка; доступный usage записывается до разбора ответа, проверки CSS и записи сниппета. Ошибки и прерванные запросы не исчезают из журнала. Старые сохранённые ходы однократно переносятся в журнал. Ранее потерянные расходы восстановить невозможно.

Панель показывает известную сумму и число попыток с неизвестной стоимостью. В настройках есть последние 30 попыток с провайдером, моделью, исходом, входными/выходными/кешированными токенами и оценкой стоимости. Полный журнал сохраняется; очистка разговора его не удаляет. Тариф и оценка фиксируются на момент запроса существующим механизмом calculateUsage; это оценка, а не выписка провайдера.

Порог расходов задаётся в USD, 0 означает отсутствие ограничения. Считается весь сохранённый журнал плагина. При достигнутом пороге или неизвестной стоимости предыдущих попыток новые запросы блокируются. Последний запрос может превысить порог: стоимость известна после ответа. Для продолжения можно повысить порог; при неизвестной стоимости потребуется отключить его. Это не жёсткий лимит биллинга провайдера.

Ограничение истории, выбор области, бесплатная регулировка, кеширование и смена моделей не реализовывались в этом шаге.

Проверка актуального изменения: TypeScript, тесты и production build. Покрыты новые CSS-свойства, несколько файлов за шаг, неизменность набора сниппетов, проверка шрифтов, Undo и отклонение ответа при параллельном редактировании. Ответы провайдеров в тестах подставные; визуальный результат в Obsidian проверяется отдельно.
