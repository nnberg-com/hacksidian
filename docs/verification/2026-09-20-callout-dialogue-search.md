# Поиск диалоговых callout’ов

Запрос: «Хочу, чтобы некоторые callout'ы (специально оформленные) отображались как диалоги в чате. Сделай.»

## Подтверждённые факты

- `callout-dialogue` («Переписка») существует в категории callout, имеет применимый CSS и селектор `[data-callout="dialogue"]`.
- В исходном текстовом ранжировании активного снимка карточка занимала 80-е место и не входила в первые 24 кандидата.
- В коде оригинал и расширения объединялись в один запрос BM25. Тест воспроизводит потерю релевантного результата при таком объединении.
- Запись самого неудачного диалога не найдена в доступной сохранённой истории. Поэтому не установлено, была ли окончательная причина этого конкретного ответа в поиске, решении модели или загруженной версии приложения.

## Исправление

- Независимая выдача для исходного запроса и каждого расширения; объединение сохраняет первые 24 кандидата каждой формулировки. Явные ID берутся только из исходного запроса.
- Вес названия выше; исследовательские описания сторонних тем исключены из текстового ранжирования. Полные записи для проверки моделью сохраняются.
- Описание «Переписки» прямо объясняет чат с чередующимися репликами, тип `[!dialogue]` и отсутствие влияния на остальные callout’ы.
- Инструкция выбора отличает подходящий opt-in эффект для специально помеченных элементов от требования изменить все элементы. Включение CSS не выдаётся за автоматическую правку заметок.
- Версия промпта изменена на `atlas-6-independent-search-queries`, чтобы старые отказы не входили в новый контекст.

## Проверка и установка

`npm --prefix plugin run check`: типы, сборка и 255 тестов прошли. Проверка по всему репозиторному атласу (>1400 применимых рецептов) ставит `callout-dialogue` первым по точной фразе. Формат 1429 карточек также проверен.

Добавлены три сценария callout’ов в `plugin/scripts/retrieval-check.ts`. Платные вызовы в этом проходе не выполнялись. Локальная выдача не доказывает итоговый ответ модели или визуальный результат в Obsidian.

Старый тест палитры исправлен: ожидаемая замена теперь зависит от текущего значения параметра, а не от первоначального красного. Пользовательский файл палитры не менялся.

Сборка установлена в `/Users/op/vaults/hacksidian/.obsidian/plugins/hacksidian`; 24 файла настроек/сниппетов проверены по хешам и не изменены. Предыдущая сборка: `/private/tmp/hacksidian-before-callout-search-7kgy3tzb`.

Для загрузки нужен перезапуск Obsidian. Для нового описания карточки нужно обновление поискового каталога; автоматически оно не выполнялось. Настройки Obsidian через чат, отложенные в OpenSpec, не реализовывались.
