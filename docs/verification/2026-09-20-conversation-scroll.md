# Стабильная прокрутка диалога

Причина: ConversationView пересоздавал всю историю при изменении turns, выгружая и повторно загружая все примеры. Высота чата сначала уменьшалась, затем асинхронно увеличивалась. Прокрутка вниз выполнялась только при отправке запроса.

Изменение: неизменившийся префикс истории остаётся в DOM вместе с загруженными примерами. ResizeObserver отслеживает размеры сообщений. В конце диалога прокрутка следует за обновлениями; при чтении истории сохраняет видимое сообщение и его смещение. Отправка нового запроса возвращает к концу. Нативное scroll anchoring отключено, чтобы не конкурировать с контроллером. Сообщения не сжимаются flex-раскладкой.

Проверено в in-app браузере на настоящих ConversationView, ConversationScroll и styles.css. Obsidian ItemView заменён минимальным DOM-хостом, ChatTechnique — примером с задержкой загрузки. Платные API не вызывались.

Воспроизводимый стенд: `node plugin/scripts/build-conversation-fixture.mjs /private/tmp/hacksidian-chat-screen`, затем HTTP-сервер этой папки и кнопка «Проверить сценарии прокрутки».

Все шесть проверок прошли: открытие в конце истории; сохранение узлов предыдущих сообщений; следование за ответом и поздним примером; сохранение позиции при новом ответе во время чтения истории; компенсация изменения высоты выше читаемого места; возобновление следования после возврата вниз. Экран стенда осмотрен.

`npm --prefix plugin run check`: typecheck, build, 265 тестов прошли.

Ограничение: доступ Computer Use к Obsidian отклонён. Нативная экранная проверка не выполнена, перезапуск установленного плагина не подтверждён.
