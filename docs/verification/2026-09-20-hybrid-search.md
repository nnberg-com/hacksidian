# Поиск по человеческому запросу и открытие карточек

Проверено 2026-09-20 на действующем снимке каталога из 1534 записей, включая 1428 применимых приёмов. Облачные файлы и оформление не менялись.

## Изменение

Запрос проходит расширение на русском и английском, затем смысловой поиск (до 50 фрагментов) и локальный BM25 по всем применимым карточкам (24 результата). Объединение кандидатов передаётся модели полными записями с ограничениями и CSS. Наличие параметров не влияет на доступность приёма. Явные ID разрешаются отдельно. Чужие и устаревшие файлы отклоняются. Расходы обоих обращений к модели суммируются и сохраняются до валидации ответа.

Применение и показ оставляют текущую вкладку. Только `ask_question` с проверенным `clarificationId` открывает отдельную карточку. Сохранённые ответы по карточке используют тот же интерактивный компонент, что и рекомендации.
