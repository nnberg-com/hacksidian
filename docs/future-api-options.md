# Возможности OpenAI API, которые нужно учитывать в будущем

Пользователь 2026-09-16 явно попросил сохранить эти возможности для будущего планирования Hacksidian. Это не поручение внедрять их сейчас.

## Batch API

Может пригодиться для массовых неинтерактивных заданий: переводов и анализа карточек, классификации, прогонов контрольных вопросов. Перед использованием перепроверить поддержку нужных операций, сроки и тарифы. Пакет запросов к моделям не равен пакетной индексации Vector Store.

Источник: https://developers.openai.com/api/docs/guides/batch

## Prompt caching

Может пригодиться для ускорения и удешевления повторяющихся запросов со стабильным префиксом инструкций. При оптимизации учитывать порядок частей запроса и измерять фактические попадания в кэш; не обещать попадание для каждого запроса. Проверять актуальные условия выбранной модели. Это не кэш готовых ответов.

Источник: https://developers.openai.com/api/docs/guides/prompt-caching
