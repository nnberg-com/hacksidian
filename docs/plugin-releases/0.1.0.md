# Hacksidian plugin 0.1.0

Первый отдельный выпуск плагина: поиск решений оформления в подключённом атласе через OpenAI, применение приёмов из карточек и интерфейс на русском и английском.

Требуется настольный Obsidian 1.8.7 или новее. Для поиска через OpenAI нужны собственный API-ключ и отдельно подготовленный атлас; обращения к API оплачиваются отдельно.

Вложения: `main.js`, `styles.css`, `manifest.json`. Атлас и песочница не входят в выпуск и обновляются пользователем отдельно.

## Установка и обновление

Нужны локальная копия репозитория Hacksidian, Node.js 22 или новее и отдельный существующий vault. Закройте Obsidian и сохраните резервную копию установленного плагина. Скачайте три вложения в отдельную папку. Из корня локального репозитория запустите:

```sh
HACKSIDIAN_VAULT="/absolute/path/to/vault" npm --prefix plugin run install:release -- "/absolute/path/to/downloaded-release"
```

Установщик копирует три файла плагина, сохраняет настройки, историю и пользовательский CSS, включает плагин и создаёт ссылки на `content/atlas` и `content/playground` локального репозитория по путям из настроек. Существующие правильные ссылки сохраняются. Конфликтующие папки не заменяются: установка останавливается без изменений. Сборка исходников и `npm ci` не нужны.

Обновление плагина выполняется той же командой; содержимое репозитория она не обновляет. Откройте Obsidian после установки.

`Source code.zip` и `Source code.tar.gz` содержат исходники и не подходят для установки плагина.
