# Локализация Hacksidian

## Реализовано

Словари интерфейса находятся в `plugin/i18n/ru.ts` и `plugin/i18n/en.ts`; общий код разрешения языка — в `plugin/i18n/index.ts`. В словарях находятся кнопки, настройки, статусы, локальные ошибки. Технические идентификаторы, CSS и пользовательские сообщения не переводятся. Сообщения внешних API и системные ошибки отображаются в исходном виде.

`interfaceLanguage`: `auto`, `ru` или `en`. По умолчанию `auto` использует публичный Obsidian API `getLanguage()`; неподдерживаемые языки заменяются английским. Минимальная версия Obsidian — 1.8.7, в которой появился этот API. Менять язык всего Obsidian для переключения плагина не требуется.

`contentLanguage`: `auto`, `ru` или `en`. По умолчанию совпадает с разрешённым языком интерфейса плагина. Навигация по раскраскам выбирает только `playground/<language>/`. Корень задаётся настройкой «Папка раскрасок». Если выбранной папки нет или она пуста, плагин сообщает об отсутствии образцов; другой язык не подставляется молча.

В каждой языковой папке десять образцов, p000.md и локальные вложения. Старые корневые заметки и общие вложения удалены; используются только языковые папки. CSS-классы и программный код сохранены; английские подписи Mermaid переведены. Относительные ссылки используют язык как часть пути и остаются внутри своей локализации. Проверка ссылок допускает намеренно отсутствующие цели демонстрационного примера.

Инструкция LLM: отвечать на языке последнего вопроса пользователя; если определить его нельзя, использовать язык интерфейса. Язык контента и настройки покрытия шрифтов этого правила не меняют. История не переводится задним числом. Выполнение инструкции моделью требует отдельной живой проверки.

## Атлас: реализованная схема

Каждый приём хранит общую карточку `<id>.md` с техническими полями и два описания `Description.ru.md` / `Description.en.md`. Локализованные title и group вынесены из общей карточки. Русские описания перенесены полностью, включая ссылки и исходные свидетельства. Все 8512 прежних файлов примеров, CSS, параметров и вложений сохранены побайтно.

Для 1395 перенесённых приёмов английские описания имеют статус pending; Markdown.en.md для них ещё нет. Генератор не подменяет отсутствующие переводы русскими. Команда `translations` показывает готовность каждого приёма; после параллельного добавления 16 новых двуязычных приёмов текущий итог — ru: 1411, en: 16. Это подготовленная структура, а не завершённый перевод всего атласа.

Оболочка генератора, кнопки, поиск, фильтры и подписи деталей локализованы. `--ui-lang` выбирает интерфейс и описание; `--lang` — пример. По умолчанию генератор читает языки из данных установленного плагина; плагин сохраняет эффективный язык Obsidian при запуске и изменении настроек. При отсутствии настроек используется английский. Явные CLI-параметры имеют приоритет.

CSS, hack.json, идентификаторы, категория, дайджесты и вложения остаются общими. Названия категорий и дайджестов выбираются по языку интерфейса. Проверка отсутствующих переводов происходит до замены предыдущей сборки. Подробности — [Генератор атласа](atlas-generator.md).

## Документация

Актуальные руководства находятся в docs/ru/ и docs/en/. Исторические STYLE-SYSTEM-* и SOURCE-README, а также инструкции legacy сохранены как архивные свидетельства прежнего состояния; они не являются актуальными двуязычными руководствами.

## Проверки

Из корня репозитория:

```sh
npm run check --prefix plugin
node tools/verify-playground.mjs
```

Вторая команда принимает необязательный путь к корню песочницы. Она проверяет все 20 образцов и локальные ссылки без изменения файлов. Unit-тесты проверяют fallback языка, независимость интерфейса и контента, соответствие ключей и параметров словарей, смену языка помощников и инструкцию чату. Они не выполняют платные LLM-запросы.


Файлы заметок имеют одинаковые коды p001–p010 в обеих локализациях; p000 — входная страница. Читаемые названия находятся только в заголовках и подписях ссылок. Код не меняется при переименовании или переводе.

## Проверено 11 сентября 2026

88 unit-тестов, TypeScript и сборка прошли. Проверены 20 образцов и 42 локальные ссылки. В установленном Obsidian подтверждены оба языка настроек, перевод подсказки панели и команд, независимый выбор языка контента (10 образцов на язык) и 32 ссылки через metadataCache. Исходные языковые настройки восстановлены. Живой LLM-вызов не выполнялся.

Проверка атласа: 28 тестов генератора прошли в `.venv-atlas`. В Chrome проверены английская оболочка и описание на двуязычном тестовом наборе, полный русский каталог, фильтры, мобильная ширина и локальные изображения. В установленном Obsidian общая карточка и Description.ru.md разрешаются в один технический приём с локализованным названием.
