# Локализация Hacksidian

## Реализовано

Словари интерфейса находятся в `plugin/i18n/ru.ts` и `plugin/i18n/en.ts`; общий код разрешения языка — в `plugin/i18n/index.ts`. В словарях находятся кнопки, настройки, статусы, локальные ошибки. Технические идентификаторы, CSS и пользовательские сообщения не переводятся. Сообщения внешних API и системные ошибки отображаются в исходном виде.

`interfaceLanguage`: `auto`, `ru` или `en`. По умолчанию `auto` использует публичный Obsidian API `getLanguage()`; неподдерживаемые языки заменяются английским. Минимальная версия Obsidian — 1.8.7, в которой появился этот API. Менять язык всего Obsidian для переключения плагина не требуется.

Песочница содержит десять русских статей `p001–p010` прямо в `content/playground/` и используемое ими SVG-вложение. Английские версии, вводные и служебные страницы удалены. Навигация показывает эти статьи при любом языке интерфейса. Для старых пользовательских песочниц с языковыми подпапками сохраняется выбор через `contentLanguage`.

Инструкция LLM: отвечать на языке последнего вопроса пользователя; если определить его нельзя, использовать язык интерфейса. Язык контента и настройки покрытия шрифтов этого правила не меняют. История не переводится задним числом. Выполнение инструкции моделью требует отдельной живой проверки.

## Атлас

Атлас доступен только на русском: единая карточка `<id>.md` с техническими полями и описанием, `markdown.md`, `recipe.css` и `hack.json`. Английские версии, подписи и ссылки удалены. Настройки и механизм переключения языков интерфейса плагина сохранены.

## Документация

Актуальные руководства находятся в docs/ru/ и docs/en/. Исторические STYLE-SYSTEM-* и SOURCE-README, а также инструкции legacy сохранены как архивные свидетельства прежнего состояния; они не являются актуальными двуязычными руководствами.

## Проверки

Из корня репозитория:

```sh
npm run check --prefix plugin
node tools/verify-playground.mjs
```

Вторая команда принимает необязательный путь к корню песочницы. Она проверяет все 10 статей и локальные ссылки без изменения файлов. Unit-тесты проверяют fallback языка, независимость интерфейса и контента, соответствие ключей и параметров словарей, смену языка помощников и инструкцию чату. Они не выполняют платные LLM-запросы.



## Проверено 11 сентября 2026

88 unit-тестов, TypeScript и сборка прошли. Проверены 20 образцов и 42 локальные ссылки. В установленном Obsidian подтверждены оба языка настроек, перевод подсказки панели и команд, независимый выбор языка контента (10 образцов на язык) и 32 ссылки через metadataCache. Исходные языковые настройки восстановлены. Живой LLM-вызов не выполнялся.

Историческая проверка браузерной версии проводилась до её удаления. Текущий атлас работает внутри Obsidian; проверки описаны в [Живых примерах](../live-examples.md).
