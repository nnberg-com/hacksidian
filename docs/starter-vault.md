# Архив из эталонного vault

Скрипт `tools/build-starter-vault.py` упаковывает уже подготовленный Obsidian vault. Он не скачивает и не обновляет плагины: в архив попадут именно те версии, которые вы установили и настроили в эталоне. Нужен Python 3.9 или новее, дополнительные библиотеки не нужны.

## Подготовка эталона

1. Создайте отдельный vault и установите нужные плагины через Obsidian.
2. Настройте плагины, редактор, тему, горячие клавиши и CSS. Проверьте материалы и навигацию.
3. Уберите личные заметки и данные: все обычные файлы vault включаются в архив.
4. Закройте Obsidian перед сборкой, чтобы файлы не менялись во время копирования.

Скрипт сохраняет настройки и CSS эталона, включая непустые CSS. Если старт должен быть без оформления, оставьте сниппеты эталона пустыми.

## Команды

Из корня репозитория, подставив свои пути:

```sh
python3 tools/build-starter-vault.py "/путь/к/Эталону" "/путь/к/архивам/Hacksidian-Starter.zip" --name "Hacksidian Starter" --dry-run
```

Это предварительная проверка без создания архива. Для сборки уберите `--dry-run`:

```sh
python3 tools/build-starter-vault.py "/путь/к/Эталону" "/путь/к/архивам/Hacksidian-Starter.zip" --name "Hacksidian Starter"
```

Путь ZIP должен быть вне эталонного vault. Существующий ZIP не перезаписывается: для новой версии выберите другое имя. `--name` задаёт одну верхнюю папку внутри ZIP; по умолчанию используется имя эталонного vault.

Дополнительные исключения задаются повторяемым параметром, например `--exclude 'Черновики' --exclude '*.log'`. Шаблоны сопоставляются с путями от корня vault. Исключение папки исключает всё её содержимое.

JSON-отчёт выводится в stdout: состав, размеры, SHA-256 файлов, версии включённых плагинов, исключения и очищенные поля без их значений. Его можно сохранить перенаправлением `> /путь/к/архивам/report.json` (также вне эталона).

## Что переносится

- Заметки и вложения, включая обычные папки `atlas/` и `playground/`.
- `.obsidian` с настройками, плагинами, темами, горячими клавишами и сниппетами.
- Содержимое символических ссылок, в том числе ссылок за пределы vault, как обычные файлы. ZIP не зависит от исходных путей. Циклические и сломанные ссылки вызывают ошибку.
- Версии плагинов из эталона без изменений. Для включённых плагинов проверяются `main.js`, `manifest.json` и совпадение ID.

## Что исключается или очищается

- Скрытые файлы и папки, кроме корневой `.obsidian`; в частности Git и корзина. Также `node_modules`, `__pycache__`, `.DS_Store`, `Thumbs.db`, `desktop.ini`.
- В `.obsidian`: папки `cache`, `caches`, `logs`, `backups`; корневые `workspace.json`, `workspace-mobile.json`, `workspaces.json`, `sync.json`, `publish.json`, `secrets.json`. Раскладка окон и вкладок не переносится.
- В JSON-файлах `.obsidian`: распознанные поля API-ключей, токенов, паролей и секретов обнуляются. Это эвристика по именам полей, а не универсальная проверка отсутствия секретов. Секреты в заметках, нестандартных полях и прочих файлах автоматически не обнаруживаются.
- В `hacksidian/data.json` сохраняются только настройки и локализация; история, расходы и служебное состояние удаляются. Отметка установки сбрасывается: первый запуск создаст отсутствующие сниппеты, сохранив подготовленные файлы и их состояние включения.

Эталон не изменяется. Вложенный vault вызывает ошибку — при необходимости исключите его через `--exclude`. Поддерживается стандартная папка конфигурации `.obsidian`. Индивидуальные абсолютные пути в настройках сторонних плагинов не переписываются автоматически: для переносимости настройте относительные пути в эталоне.

## Развёртывание

1. Распакуйте ZIP в новое место.
2. В Obsidian выберите «Открыть папку как хранилище» и укажите верхнюю папку из архива.
3. При запросе разрешите использование сторонних плагинов. Введите собственные ключи доступа, если они нужны.
4. Проверьте Folder Notes, Dataview, атлас и песочницу.

Не распаковывайте стартовый архив поверх рабочего vault: это комплект для нового развёртывания. Для распространения третьим лицам добавьте лицензии включённых компонентов и выполните их условия; скрипт не загружает лицензии автоматически.

## Проверка скрипта

```sh
python3 -m unittest discover -s tools/tests -p 'test_starter_vault.py' -v
```

Тесты используют временные vault и проверяют содержимое ZIP, сохранение настроек и CSS, очистку приватного состояния, перенос символических ссылок, ошибки и неизменность эталона. Это не заменяет проверку готового комплекта после открытия в Obsidian.
