# Единый CSS всех приёмов

Переведены все **1 411** карточек: **1 389** с CSS, **22** примера разметки с пустым recipe.css.
Принятый пользователем task-e30 сохранён без изменений.

## Что теперь является источником

В каждой папке приёма один `recipe.css`. `hack.json` содержит `format: 2`, целевой
сниппет, наличие CSS и, где нужно, требования к разметке. Атлас и плагин читают
CSS без преобразований. Компилятор шаблонов удалён из исполнения плагина.
Повторное применение заменяет блок выбранного приёма, сохраняя обычный Undo.
Автоматическое включение всего каталога не выполнялось.

## Воспроизводимость и исходники до переноса

- `tools/migrate-recipes.mjs` — однократный импорт старых шаблонов; не часть плагина.
- `tools/recipe-migration/` — импорт и нормализация исходной разметки.
- `tools/verify-recipe-catalog.mjs` — полная проверка единства CSS и обновления блоков.
- `build/recipe-migration-originals/` — исходные затронутые файлы до переноса.
- `build/recipe-migration-report.json` — полный список карточек и изменений.
- `build/recipe-verification.json` — результат полной сверки.

При повторной нормализации запускаются import, normalize-native-selectors,
normalize-interface-models и normalize-editor-models, затем сборка и verify.
`--from-backup` предназначен только для осознанного пересоздания миграции из
сохранённых старых исходников: он перезаписывает recipe.css.
